# 从零开发一个极简 Harness：以 Tiness 为例

这套教材解释一件事：怎样把模型提出的行动，变成一个可执行、可中断、有边界、能追溯的终端程序。

我们以当前 Tiness 源码为实现样本，从需求和取舍出发，再逐步进入组件。你将学到的不只是一个 `while` 循环，而是如何确定程序必须保证什么、哪些决定交给模型、哪些功能在第一版主动舍弃。

适合已能阅读 TypeScript、理解 Promise 和基本文件操作的学员。不要求使用过 Agent 框架。建议一边阅读，一边打开源码；代码围栏中的“源码节选”保留实际逻辑，“教学骨架”用于解释顺序，不能直接替代完整实现。

每章都按“问题 → 核心流程 → 原理和代码 → 取舍 → 小练习”的思路展开。练习的目的不是一次重写整个项目，而是一次观察或实现一个有明确结果的行为。

## 贯穿案例

在一个练习工作区里，有一个计算函数和一份失败测试。用户提出：

> 请检查失败原因，先列计划，修复计算函数，运行测试，并说明你实际验证了什么。

运行中，用户又输入：

> 前面的请求结束后，再总结本次改动。

随后在另一次长命令执行时按 Esc。这个小案例能覆盖工具循环、计划、审批、排队、上下文、日志和中断。它比“搭建一个大型自动化平台”更适合观察 Harness 的责任。

## 对照源码的方法

教材位于项目根目录的 `教材/从零开发极简Harness/`。文中的相对源码链接可以直接打开对应文件。核心参考是 [设计文档](../../Tiness%20设计文档.md)、[项目说明](../../README.md) 和 [测试报告](../../TESTING.md)。本教材依据 2026-09-11 的当前实现编写，不承诺后续源码改动自动同步到教材。

教材讲解的是这个项目的协议选择和设计，不是某个 API 的完整使用手册。配置字段以 [defaults.json](../../src/defaults.json) 为准，模型能力和实际上下文窗口需与所配置端点相符。

图全部使用 Mermaid 源码。在支持 Mermaid 的 Markdown 阅读器中查看即可；不支持时仍可读取节点和连接关系。阅读顺序可以先完成 01—08 的执行主线，再读辅助组件。
